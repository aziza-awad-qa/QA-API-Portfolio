# API Test Plan

## Project
DummyJSON REST API

## Module
Posts API

## Objective
Verify that the Posts API functions correctly and returns the expected responses.

## Scope
- GET All Posts
- GET Single Post
- POST Create Post
- PUT Update Post
- PATCH Update Post
- DELETE Post

## Testing Types
- Functional Testing
- API Testing
- Positive Testing
- Negative Testing

## Tools
- Postman
- Git
- GitHub

## Test Environment
- DummyJSON Public API
- Windows 10/11
- Internet Connection

## Entry Criteria
- API endpoint is available.
- Postman is installed.
- Internet connection is available.

## Exit Criteria
- All planned test cases are executed.
- All critical defects are reported.
